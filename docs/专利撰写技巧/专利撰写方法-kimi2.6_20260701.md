专利文档方法撰写技巧说明

1. 写主要权利要求书(简称主权)
   撰写技巧
   本发明的主要步骤，发明物结构等说明。注意，主权不要写得太具体，比如具体实现的模型结构，或者具体参数，不用写出来。否则专利所包含的范围很小，专利的价值不是很大。具体的方法在实施例中进行说明即可。
   标准的专利应该是在副权利要求中说明，现在我们自己写专利时，不需要写副权，专利代理人会帮我们完成。
   对于一个专利，我们应该写一个方法以及它对应的一个系统，所以在权利要求书中，应该写这个系统实际运行时的整个流程，或者这个系统的组成的各个部分。不只是单纯的写一个优化方法。比如下面的两个例子，一个是不好的例子，一个是较好的例子。
   不好的示例
   一种基于强化学习和可验证奖励的三维目标检测优化方法，其特征在于，包括以下步骤：
   S1. 获取输入数据： 获取待处理的带有真值标注的三维场景数据以及针对所述三维场景数据的目标检测指令；所述真值标注至少包含场景中目标的三维边界框和类别属性信息；
   S2. 生成候选响应： 将所述三维场景数据和目标检测指令输入至一个预设的、支持强化学习策略优化的三维检测模型，所述模型根据当前策略生成至少一个候选响应，其中每个候选响应包含用于描述三维目标检测结果的推理过程和具体的三维目标信息；

## 一、核心原则：主权写什么、不写什么

### 1.1 主权必须写的：方法实际运行的完整流程

主权描述的是**该方法在实际应用时，从头到尾的运行流程**。不是描述内部某个模块如何优化，而是写整个方法实际用起来有哪些步骤。

**好判断标准**：读完主权，应该能清楚回答"这个方法实际运行时，输入什么、经过哪几步、输出什么"。

### 1.2 主权绝对不写的：具体实现细节

| 不能写的 | 示例（错误的） | 正确做法 |
|---------|--------------|---------|
| 具体模型名称 | "采用DINOv3模型" | "采用预训练视觉基础模型" |
| 具体模型架构 | "Vision Transformer架构，70亿参数" | 不写，实施例中再提 |
| 具体参数值 | "k=4, t=0.5, 3x3高斯核" | "k为大于等于1的整数" |
| 具体优化算法 | "采用策略梯度算法更新参数" | "采用策略优化算法更新参数" |
| 内部训练细节 | "用交叉熵损失函数训练100轮" | 不写，实施例中再提 |
| 公式细节 | "IoU = intersection / union" | "计算交并比"或直接引用概念 |

**核心逻辑**：主权中任何写了具体名称的地方，都等于把保护范围缩小到只有这个具体方案。要用**上位概念**代替具体名称。

### 1.3 上位概念替换法则

写主权时，遇到具体的技术名词，按以下规则替换：

| 层级 | 写法 | 适用位置 |
|------|------|---------|
| 最上位 | "所述xxx包括但不限于A、B、C等" | 主权中对关键概念的定义 |
| 上位 | "所述xxx为yyyy"（功能描述） | 主权中首次出现该概念时 |
| 具体 | "本实施例中，采用A模型" | 只在实施例中出现 |

**例**：
- 主权写：`所述图像重建模型包括但不限于自编码模型、可逆神经网络、GAN网络等`
- 实施例写：`本实施例中，图像重建模型采用AutoEncoder模型`

## 二、主权结构模板

### 2.1 方法权利要求的结构

```
一种基于[主题]的[方法名称]，其特征在于，包括以下步骤：

S1. [数据采集步骤]：获取[输入数据类型]，得到[数据名称]；
S2. [核心处理步骤1]：对所述[数据名称]进行[处理操作]，得到[中间结果]；
S3. [核心处理步骤2]：将所述[中间结果]输入[模型类型]，得到[输出结果]；
S4. [最终输出步骤]：基于所述[输出结果]，进行[最终判断/操作]，输出[最终结果]。
```

**要点**：
- 每一步只写"做什么"，不写"怎么做"
- 涉及模型的地方，只写模型类型（如"图像重建模型"），不写具体模型名称
- 涉及参数的地方，只写参数的含义，不写具体数值

### 2.2 主权中关键概念的首次定义

主权中第一次出现的**创新概念**或**有特殊性质的名词**，需要用`所述...包括但不限于...`或`所述...为...`进行定义。

**例**：
```
S1. 采集样本图片，获取训练样本图片以及待检测样本图片；
```
这里"训练样本图片"有特殊性质——它是不含有异常的图片。这个特殊性质在主权中先不展开，在副权或实施例中说明。

**另一个例**：
```
S2. 对所述训练样本图片和待检测图片进行异常预处理，抑制图片中的
    微小异常，得到预处理图片；
```
"异常预处理"是创新概念，主权只写它的功能（抑制微小异常），不写具体实现（用什么滤波器、什么核）。

### 2.3 系统权利要求的结构

系统权利要求与方法步骤**一一对应**，每个模块对应方法中的一个步骤。

```
一种基于[主题]的[系统名称]，其特征在于，包括：

[模块A]，用于[对应S1的功能描述]；
[模块B]，用于[对应S2的功能描述]；
[模块C]，用于[对应S3的功能描述]；
[模块D]，用于[对应S4的功能描述]。
```

**要点**：
- 模块名称与方法步骤中的操作对应
- 每个模块只用一句话描述功能
- 不写模块内部的具体实现

## 三、副权（从属权利要求）的写法

### 3.1 副权的作用

副权对主权中的**关键概念**进行限定和展开，扩大保护范围。只写核心概念，不写每个细节。

### 3.2 需要写副权的情况

对主权中的以下元素写副权：

1. **有特殊性质的名词** —— 如"训练样本图片为不含有异常的图片"
2. **创新方法/概念** —— 如"异常预处理包括但不限于图像模糊处理或者图像去噪..."
3. **使用的模型类型** —— 如"图像重建模型包括但不限于自编码模型、可逆神经网络..."
4. **模型的训练过程** —— 如"将预处理图片输入图像重建模型之前，还包括：构建模型、训练模型..."
5. **关键步骤的具体子流程** —— 如步骤S4的判断子流程

### 3.3 副权不写的

- 具体的参数值（如k=4, t=0.5）
- 具体的模型架构细节
- 具体的训练超参数

## 四、实施例的写法

### 4.1 实施例的整体结构

实施例 = 主权步骤复制 + 每步骤的三段式展开

### 4.2 每步骤的三段式格式

每个步骤后面，按以下三段展开：

```
S[编号]. [步骤描述]；

其中，所述[概念A]为[特殊性质说明/概念定义]；
其中，所述[概念B]包括但不限于[C]、[D]、[E]；

本实施例中，其具体实现为：[具体的实现方式]。
```

### 4.3 三段式的详细规则

#### 第一段："其中"说明段

对步骤中出现的**以下类型的名词**进行说明：

| 类型 | 说明方式 | 示例 |
|------|---------|------|
| 有特殊性质的名词 | `所述xxx为[性质]` | `所述训练样本图片为不含有异常的图片` |
| 创新方法/概念 | `所述xxx包括但不限于[A]、[B]` | `所述异常预处理包括但不限于图像模糊处理` |
| 使用的模型 | `所述xxx包括但不限于[A]、[B]模型` | `所述图像重建模型包括但不限于自编码模型` |
| 需要展开定义的参数 | `所述xxx由[方式]确定` | `所述k的值由实际应用场景决定` |

**注意**：
- 多个"其中"可以连续写
- "其中"段只写概念性说明，不写具体实现

#### 第二段："本实施例中"实现段

写该步骤在**本实施例中具体怎么实现**的，包括：

| 内容 | 示例 |
|------|------|
| 具体使用的模型 | `图像重建模型采用AutoEncoder模型` |
| 具体参数值 | `用3x3的高斯核对图像进行模糊处理` |
| 具体阈值 | `从t=0.5开始，每次增加0.05` |
| 具体训练流程 | 用子步骤a、b、c描述 |
| 具体数据来源 | `在实际的生产制造场景中，用图像采集系统采集...` |

**注意**：
- 具体实现只出现在"本实施例中"这一段
- 如果涉及模型训练，需要给出训练流程的示意图，并在实施例中结合图片说明

### 4.4 模型训练流程的写法

如果某步骤涉及使用了一个需要训练的模型，实施例中需要：

1. **先说明模型的概念类型**（在"其中"段）
2. **再说明训练过程**（在"本实施例中"段）
3. **训练流程用子步骤a、b、c描述**
4. **给出训练流程示意图**

**例**：
```
S3. 将所述预处理图片输入图像重建模型，得到重建图片；

其中，所述图像重建模型包括但不限于自编码模型、可逆神经网络、GAN网络等；

进一步地，将所述预处理图片输入图像重建模型之前，还包括：
    a. 基于自编码模型或可逆神经网络或GAN网络构建一个图像重建模型；
    b. 用不含有异常的训练样本训练所述图像重建模型，得到最终的图像重建模型。

本实施例中，图像重建模型采用AutoEncoder模型。训练步骤如图2所示：
    a. 构建一个AutoEncoder模型；
    b. 将训练样本通过图像高斯模糊处理并用形态学操作中的膨胀腐蚀对图像
       进一步处理，抑制微小异常，得到预处理训练样本；
    c. 利用预处理训练样本训练AutoEncoder，得到最终的图像重建模型。

进一步的，将待检测得到的预处理图片输入图像重建模型，得到重建图片。
```

### 4.5 实施例二的写法（系统实施例）

系统实施例与系统权利要求对应，每个模块一句话功能描述 + 具体实现。

**结构**：
```
实施例二

[系统名称]包括：[模块A]、[模块B]、[模块C]。

[模块A]，用于[功能描述]；
本实施例中，具体实现为：[具体实现方式]。

[模块B]，用于[功能描述]；
本实施例中，具体实现为：[具体实现方式]。

[模块C]，用于[功能描述]；
本实施例中，具体实现为：[具体实现方式]。
```

## 五、典型错误对照表

| 错误类型 | 错误示例 | 正确写法 |
|---------|---------|---------|
| 主权写太具体 | `采用YOLOv8进行2D检测` | `通过预训练目标检测模型生成二维候选框` |
| 主权写训练细节 | `用Adam优化器训练100轮，学习率0.001` | 不写，实施例中提 |
| 主权写公式 | `IoU = (A∩B) / (A∪B)` | `计算交并比`或直接引用"IoU" |
| 主权写参数值 | `阈值t=0.5` | `阈值t`或`预设阈值` |
| 主权写架构细节 | `采用ResNet-50 backbone + FPN` | `采用特征提取网络` |
| 上位概念不够上位 | `采用深度学习模型` | `采用包括但不限于深度学习模型的方法` |
| 实施例缺"其中"段 | 直接写"本实施例中" | 先写"其中，所述xxx为..." |
| 实施例缺具体值 | `用高斯核对图像进行模糊处理` | `用3x3的高斯核对图像进行模糊处理` |

## 六、快速检查清单

写完主权后，逐条检查：

- [ ] 主权描述的是方法实际运行的完整流程，不是内部优化方法
- [ ] 主权中没有出现具体模型名称（用了上位概念）
- [ ] 主权中没有出现具体参数值
- [ ] 主权中没有出现具体训练超参数
- [ ] 主权中没有出现具体模型架构描述
- [ ] 关键概念首次出现时用了"所述"
- [ ] 需要限定的关键概念在副权中有展开
- [ ] 系统权利要求与方法步骤一一对应

写完实施例后，逐条检查：

- [ ] 每个步骤都有"其中"说明段（对特殊名词/创新概念进行说明）
- [ ] 每个步骤都有"本实施例中"实现段（给出具体模型/参数/值）
- [ ] 涉及模型的步骤有训练流程说明
- [ ] 涉及训练流程的有示意图引用
- [ ] 系统实施例中每个模块有具体实现
